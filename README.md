# flashAndSayPages

The static website for the **Flash & Say** iOS app (GitHub Pages).

- `index.html`: landing page (marketing URL)
- `privacy.html`: privacy policy (App Store privacy policy URL)
- `support.html`: FAQ and contact (App Store support URL)
- `assets/style.css`, `assets/*.png`

Expected URLs: https://gregalton.github.io/flashAndSayPages/ plus `privacy.html` and `support.html`.

To publish: push to GitHub, then go to Settings › Pages › Deploy from branch › `main` / root.
